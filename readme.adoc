= bookcomposer

A book and zine imposition tool. The engine is a pure TypeScript layout library (no UI, no PDF) that works out where each source page lands on each printed sheet.

Status: in development.

== Using the engine

`impose()` takes the PDF's page sizes, the book's parts and the print settings, and returns a `Layout`: where every page lands on each side of each sheet, plus cut and fold lines. All sizes are PDF points.

This is a 76-page PDF of 4 x 5.25 inch pages, bound as a front board, 9 folio signatures and a back board, printed on US Letter:

[source,ts]
----
import { impose } from './engine/src/index.ts'

const layout = impose({
  pageSizes: Array.from({ length: 76 }, () => ({ width: 288, height: 378 })),
  parts: [{ type: 'board' }, { type: 'body', signatures: 9, folds: 1 }, { type: 'board' }],
  print: { sheet: { width: 612, height: 792 }, duplex: 'long-edge', margin: 18, gap: 0, bleed: 0 },
  mismatch: 'fit',
})

layout.sheets.length // 10
layout.issues        // [] (errors and warnings, each with a code)
----

== Setup

Needs Node (for the engine) and Rust. The exporter loads the PDFium library at runtime; download it once:

[source,sh]
----
make fetch-pdfium
----

== Command line

`scripts/impose-pdf` turns a book PDF into a print-ready sheets PDF. Page content is embedded as vector content, never rasterized or re-encoded.

This imposes a 76-page book as a front board, 9 signatures and a back board on US Letter, with cut marks:

[source,sh]
----
scripts/impose-pdf --input book.pdf --output sheets.pdf \
  --signatures 9 --front-board --back-board --sheet letter --margin 18 --cut-marks
----

Other flags: `--folds 1|2|3`, `--sheet letter|a4|tabloid|a3|WxH`, `--gap`, `--bleed`, `--duplex long-edge|short-edge`, `--fold-marks` and `--keep-temp DIR` (keeps the intermediate layout JSON). Layout warnings print to stderr; layout errors stop the run. `scripts/impose-pdf --help` lists everything.

A page's trim size is its TrimBox, or its CropBox when it has none, or its MediaBox.

Not carried over (yet): annotations and form fields. A warning names each page that has any.

== Running the app

[source,sh]
----
make app-dev
----

Open http://127.0.0.1:5173. On a remote box, forward the port first: `ssh -L 5173:127.0.0.1:5173 <host>`.

Choose a book PDF, then set signatures, folds, boards and sheet size (Letter, A4, Tabloid, A3 or custom). The workspace shows the parts and where each page lands, the sheets one at a time with cut and fold lines, and any layout warnings or errors. Everything updates as you change a setting. *Suggest* next to Signatures picks a count for the current folds and boards. A board's panel says what blank filler pieces to cut.

*Save project* writes the settings to a `.bookcomposer.json` file. Open it from the start screen and choose the same PDF to continue. *Export PDF* saves `<name>-imposed.pdf` with the page content embedded as vector content, and lists anything the exporter could not carry over, such as annotations. It is disabled while the layout has errors.

== Developing

`make` lists every dev task. The PDF export crate (`crates/pdf-export`) needs Rust and the PDFium library, which `make fetch-pdfium` downloads into `vendor/pdfium/`.

From a fresh clone:

[source,sh]
----
(cd engine && npm install)
(cd app && npm install)
make fetch-pdfium
make app-browsers  # Chromium for the app's browser tests
make test          # all tests: engine, pdf-export, app, Tauri commands
make app-check     # typecheck the app
make app-e2e       # the app's browser tests
make tauri-test    # the Tauri app's commands
make app-dev       # run the app
----

Other tasks:

[source,sh]
----
make e2e         # end-to-end impose-pdf test
make release     # release export binary
make typecheck   # engine
make lint        # rustfmt and clippy
make tauri-check # compile the Tauri app (on Linux, needs the webkit2gtk-4.1 dev libraries)
----

The Makefile expects the Rust toolchain in `RUSTUP_BIN` (default `/home/linuxbrew/.linuxbrew/opt/rustup/bin`) and loads PDFium from `BOOKCOMPOSER_PDFIUM_DIR` (default `vendor/pdfium/lib`); override either on the command line, e.g. `make test RUSTUP_BIN=~/.cargo/bin`.
